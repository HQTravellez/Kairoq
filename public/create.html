                              App Store and Google Play

                              Turn on This is a mobile app, then:

                              • Download the iOS + Android project (ZIP): open it in Android Studio or Xcode (npm run android / npm run ios).
                              • Or push it to GitHub from Settings: every push builds an Android APK you can install, under Actions → Artifacts.
                              • Publishing to the stores needs your own Apple Developer and Google Play accounts.
