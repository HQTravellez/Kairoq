# Listing Kairoq in awesome-paperclip

The community directory is https://github.com/gsxdsm/awesome-paperclip. To get listed: fork it, add the line below under **Tools & Utilities** (where the other MCP servers are), and open a pull request with a clear title and description. This has to come from the Kairoq account, not from an automated session.

Suggested line:

```
- [Kairoq](https://github.com/HQTravellez/Kairoq) - MCP server that builds, tests and publishes web apps from plain English: agents create a project, follow the build, send AI customers through it and go live on a free URL.
```

Suggested pull request title: `Add Kairoq (app builder MCP server)`

Suggested pull request description:

> Kairoq is an app builder with an MCP server (Streamable HTTP, API-key auth). Connected as "your own MCP server", Paperclip agents get `create_project`, `build`, `get_job`, `get_project`, `publish`, `run_synthetic_test` and `fix_and_retest`: every change is tested in a real browser before it is saved, and AI customers try the app and report where they got stuck. Docs: https://github.com/HQTravellez/Kairoq/blob/main/docs/create.md#api-keys-and-the-mcp-server
